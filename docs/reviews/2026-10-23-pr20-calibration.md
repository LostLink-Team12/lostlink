# PR #20 标定产物一致性修复

默认阈值网格统一覆盖余弦相似度范围 -1 到 1，步长 0.01，CLI 与共享标定模块使用同一组默认值。JSON 报告记录本次实际搜索网格；Markdown 的推荐值和精确率目标直接读取 JSON，不再独立推荐。用户显式限制搜索区间时，Markdown 也遵循该区间，不会把区间外结果写成建议。

0.25 在摘要中标为历史基线；当前运行时默认值由 #22 设置为照片 0.78、纯文字 0.63。标定工作流只生成证据，不会自动改动运行时配置或部署。数据集包含重复场景、同图正例且没有独立验证集，仍不能将结果解释为生产质量保证。

回归用例覆盖高于旧上界 0.45 的有效阈值、自定义区间无解、JSON 自定义精确率目标，以及没有 JSON 输入时的默认行为。
