# Frontend (owner: ZHANG JI)

- `venue-portal/` - venue staff: log in, register found items with photos, review and approve claims (UC1, UC2, UC5)
- `owner-app/` - owners: report lost items, search by text or photo, see matches, submit claims (UC3, UC4, UC5)

Stack: React + Vite + TypeScript, Cognito Hosted UI for login. Built as static sites served from S3 + CloudFront.
